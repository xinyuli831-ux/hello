자기소개

※ 본 포트폴리오는 스토리 구성과 화면 검증을 위한 샘플(가상) 포트폴리오입니다. 실제 제출·공개 전 본인의 검증된 이력, 확인 가능한 산출물 링크, 공개 범위 검토 결과로 교체해야 합니다.

1단계 · 문제의 출발점: 솔담대학교 경영정보학과에서 데이터 분석과 경영정보시스템(MIS)을 공부하며, "현장의 데이터가 왜 흔들리고, 어떤 지표가 실제 운영 결정을 바꾸는가"에 관심을 갖게 되었습니다.

2단계 · 현장 검증과 확장: 학술동아리와 경진대회에서 가정용 전력 패턴과 지역 재생에너지 불균형을 분석한 뒤, 여울데이터랩 인턴십을 통해 고객 문의 텍스트 분류와 같은 실제 업무 흐름 속 데이터 문제를 다뤘습니다.

3단계 · 앞으로의 방향: AI가 요약한 문장을 그대로 옮기기보다, 데이터 출처와 한계를 직접 설명할 수 있는 분석가로서 에너지 산업의 디지털 전환과 운영 효율 개선에 기여하고자 합니다.

캐릭터, 듀얼 모니터, 책상과 식물을 한 장면에 구성한 데이터 작업실 일러스트입니다.

마우스를 움직이거나 페이지를 스크롤해 보세요.

프로젝트 성장 스토리 (총 3건)

01 | 가정용 전력 사용 패턴 분석
기초 분석 · 시계열 탐색

주제 : 전력 소비 피크 구간 파악 및 절감 가이드

공개 전력 데이터를 정제해 시간대별 소비 흐름과 이상치를 살피고, 직접 설명할 수 있는 기초 시계열 대시보드를 만들었습니다.

02 | 지역 신재생 수급 불균형 분석
데이터 결합 · 시각화 리포트

주제 : 태양광 발전량과 지역 수요 격차 진단

단일 시계열 분석을 넘어 발전량과 수요 데이터를 결합해 불균형 구간을 시각화하고, 팀 발표용 리포트로 정리했습니다.

03 | 고객 문의 텍스트 자동 분류
인턴 과제 · 업무 흐름 개선

주제 : 상담 문의 유형 분류 프로토타입 및 효율화 제안

실제 업무 환경에서 반복 문의 분류 기준을 정립하고, 라벨링·전처리·분류 실험 결과를 바탕으로 운영 개선안을 제안했습니다.

보유 역량

데이터 분석 & 검증 역량

  • Python (Pandas, Matplotlib, Seaborn)으로 결측치·이상치 점검 및 탐색적 분석 수행
  • SQL을 활용한 조건 조회, 집계, 테이블 결합 및 정제 파이프라인 정리
  • 시계열 추세와 지역 비교 차트를 통한 핵심 변화 지점 시각화
  • 모델 결과의 한계와 가정(Assumption)을 분리해 설명하는 습관

경영 맥락 & 커뮤니케이션

  • 경영정보시스템(MIS) 관점에서 데이터 흐름과 현장 업무 프로세스 연결
  • 분석 목적·근거·실행 제안을 구분한 명확한 보고서 및 발표 자료 작성
  • 팀 프로젝트에서 역할 분담, 데이터 기준 합의, 리뷰 피드백 반영
  • Excel 피벗/함수 및 프레젠테이션을 활용한 실무형 문서 정리

활동 기록

  • 여울데이터랩 인턴｜고객 문의 데이터 정제 및 분류 프로토타입 보조 반복 문의 라벨링 기준을 정리하고 분류 결과 통계를 시각화해 상담 분류 업무 부담을 줄이는 방향을 제안했습니다.
  • 별숲 데이터 챌린지 참가｜지역 신재생 에너지 수급 불균형 분석 팀원 태양광 발전 데이터와 지역 수요 데이터를 결합해 수급 차이 구간을 도출하고, 시각화 리포트와 팀 발표를 맡았습니다.
  • 교내 경영데이터 경진대회｜기업 판매 데이터 분석 우수상 수상 판매 추이와 채널별 성과를 비교 분석해 재고·프로모션 운영 개선 포인트를 도출했습니다.
  • 솔담대학교 경영정보학과 학술동아리｜데이터 분석 스터디 및 학기별 과제 발표 매 학기 분석 코드를 동료들에게 직접 설명하며, 결과 수치보다 데이터 해석의 타당성을 검증하는 연습을 이어왔습니다.

포트폴리오 다듬기 기준 (사실 · 근거 · 책임)

AI가 작성한 문장을 그대로 옮기지 않고, 내가 직접 설명할 수 있는 포트폴리오로 만들기 위한 점검 기준입니다.

1. 사실 (검증한 경험)

전공, 역할, 수상 내역, 기간을 내 실제 사실로 교체하세요. 과장된 수식 대신 내가 실제로 수행한 작업과 한계를 명확히 적습니다.

2. 근거 (확인 가능한 산출물)

분석 노트북·코드 저장소, 대시보드 캡처/링크, 발표 자료, 사용한 데이터 출처 등 외부에서 확인 가능한 근거를 연결하세요.

3. 책임 (공개 범위 점검)

연락처, 인턴/협업 데이터, 타인 정보 등 외부에 공개해도 되는 범위인지 확인하고, 비공개 자료나 민감 정보는 제외하세요.
