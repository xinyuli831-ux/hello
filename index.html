자기소개

※ 본 포트폴리오의 모든 학력, 경력, 프로젝트는 가상으로 제작된 내용입니다.

안녕하세요, 솔담대학교 경영정보학과 윤서하입니다. 데이터 분석과 경영 정보 시스템을 바탕으로 에너지 산업의 디지털 전환에 기여하고 싶어 모아빛에너지에 지원했습니다.

여울데이터랩 인턴과 별숲 데이터 챌린지 참가를 통해 데이터 수집·정제, 시각화, 간단한 예측 모델링 경험을 쌓았습니다. 경영 지식과 데이터 기술을 결합해 현장의 의사결정을 돕는 실용적인 분석가가 되는 것이 목표입니다.

꼼꼼한 데이터 검토와 명확한 결과 공유를 중요하게 생각하며, 팀원들과 논의하며 문제를 정의하고 해결하는 것을 선호합니다.

캐릭터, 듀얼 모니터, 책상과 식물을 한 장면에 구성한 데이터 작업실 일러스트입니다[cite: 1, 2].

마우스를 움직이거나 페이지를 스크롤해 보세요[cite: 2].

프로젝트 (총 3건)

프로젝트 1 | 에너지 사용 패턴 분석

주제 : 가정용 전력 사용량 패턴 분석 및 절감 제안

공공 에너지 데이터를 활용해 사용 패턴을 분석하고, 시계열 기반의 간단한 소비 예측 대시보드를 제작했습니다.

프로젝트 2 | 고객 문의 텍스트 분류

주제 : 에너지 기업 고객센터 문의 텍스트 자동 분류

여울데이터랩 인턴 과제로, 고객 상담 텍스트를 카테고리별로 분류해 업무 효율화 방안을 도출했습니다.

프로젝트 3 | 별숲 데이터 챌린지

주제 : 지역 신재생 에너지 수요-공급 불균형 분석

별숲 데이터 챌린지 출전 프로젝트로, 태양광 발전 데이터와 지역 수요 데이터를 결합해 시각화 리포트를 작성했습니다.
